V23 changes:
- Game and Anime category filters use prebuilt local archive indexes for near-instant filtering.
- Category buttons no longer rebuild the toolbar on every click.
- Search uses the same local index and schedules one render frame at a time.
- Initial game/anime batch is 24 cards instead of 48 for faster first paint.
- Archive cards are excluded from the page-wide reveal observer and use content-visibility for cheaper rendering.
- Supabase client is loaded after the initial site paint instead of blocking the critical render path.
- Initial cloud session/data requests run in parallel.
- Existing category/status formats are normalized before filtering.


V23 reliability/performance fixes:
- Archive filter clicks reuse a fixed DOM card pool instead of destroying/recreating poster/image nodes.
- Search and category matching use prebuilt category sets and a single local scan with no network wait.
- Save operations are optimistic: local state updates and the current page renders immediately.
- Cloud writes run in the background with revision coalescing and automatic retry.
- Full-archive cloning was removed from the save interaction path.
- Supabase JS is not loaded for public visitors; public cloud reads use lightweight REST and background polling.
- Cursor animation only runs while the pointer is moving instead of using an idle RAF loop.
- Archive cards use layout/paint containment for cheaper scrolling and filtering.
