LUCIAN VEX V8

Public site: viewers see the portfolio, Discord-style profile card and THEME controls only.
Owner mode: Ctrl+Shift+L, then enter the owner code configured in script.js.

DISCORD PROFILE
- Open Owner Mode > EDIT DISCORD PROFILE.
- Manually set display name, username, status, custom status, About Me, member-since text, avatar, banner and decoration.
- Use local image buttons for avatar/banner/decoration or URLs.
- This is intentionally NOT connected to Discord live presence.

WALLPAPERS
- Open THEME while Owner Mode is unlocked.
- Choose Cyber Flow, Neon Aurora, System Scan, Violet Nexus or Static.
- Upload Background Image for a custom static background.
- Upload Live Wallpaper for a local MP4/WebM (small files recommended).
- Hosted video URLs are better for large wallpapers.
- Adjust intensity, blur and content dimmer.

PUBLISHING CHANGES
- Use EXPORT in Owner Mode to download data.js.
- Replace data.js in your GitHub Pages repository and commit the change.
